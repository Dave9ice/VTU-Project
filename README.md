# VTU Platform – Virtual Top-Up App 📲💳

A web-based Virtual Top-Up (VTU) platform that allows users to purchase airtime, data bundles, and other digital services online.

## 🚀 Features

- ✅ User authentication (JWT-based)
- 📱 Buy airtime and data from major providers
- 📊 Admin dashboard to manage users and transactions
- 💬 Transaction history and real-time feedback
- 🌐 Third-party API integration for VTU services
- 💡 Error handling, loading states, and responsive UI

## 🛠 Tech Stack

- **Frontend:** React, Bootstrap (or CSS framework used)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB + Mongoose
- **Authentication:** JWT, bcrypt
- **API Integration:** External VTU service provider
